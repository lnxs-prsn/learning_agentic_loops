# learning_agentic_loops

A factory for building agentic loops. The loops already here have been used by many projects; they are example loops the factory references when building future loops.

**State:** aim confirmed 2026-10-18; the factory itself is not defined or built yet (next stage: define what it takes in, what it produces, and how it uses the examples).

## Map
- **Example loops** (multi-agent role prompts, each with a runner): `planning_agents/`, `delivery_agents/`, `architecture_agents/`, `greenfield_agents/`, `debug_agents/`, `refactor_agents/`, `migration_agents/`, `fiction/` (story generation; spec in `fiction_build_spec.md`).
- `data_to_improve_loops/`: a smaller copy of the planning loop (origin unrecorded).
- `initial_build.md`: an example delivery spec, as fed to the delivery loop.
- `insights_for_loops.md`: the owner's design notes on how loops should work.

# Intent block for tickets / work orders (proposal, METHOD §5)

Add at the top of any ticket or task handed to another agent. It doesn't replace the existing ticket fields (write-set, acceptance, constraints); those are the fences. This adds the direction, so initiative points the right way (agent adaptation A7).

```
## Intent
What: <the task>  in order to  Why: <purpose; the parent task's What>
Serves: <current intent BR-n> → <aim AIM-n>
Main effort of this ticket: <the one part that must succeed>
Freedoms: <what the implementer may decide>
Constraints / anti-goals: <what must not happen> (existing Write-set and Constraints sections still apply)
Backbrief: <short backbrief in the implementer log before starting>
```
